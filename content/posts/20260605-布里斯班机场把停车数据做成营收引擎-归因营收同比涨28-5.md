**归因营收同比增长 28.5%，活跃客户增长 11.95%。**这是布里斯班机场和 SAP Engagement Cloud 合作三年后拿到的两个数字。

FY24 服务 2260 万旅客的澳洲第三大机场，靠的不是再搞一个会员 APP，也不是去铺一波广告，而是把停车预订、电商交易、旅客行为这些散在不同系统里的数据先连起来，再把"客户"这个抽象概念拆成具体可识别的几类人，最后用对的渠道在对的时间点把对的内容推过去。

说起来朴素，但很多客户做不到的恰恰就是这一步。

## 一、Before：守着金矿在数孤岛

机场是一个奇怪的商业体——它既是基础设施，又是一个综合体零售商。布里斯班机场旗下有零售、停车、电商、租赁、地产开发等多条线。每条线都在产生数据，每条线又都各自管自己的客户视图。

三年前的状态：

- 数据孤岛严重，跨业务线的客户画像拼不起来；
- 营销动作没法识别"这个旅客是谁"——是商务出差、家庭度假，还是矿区轮班（澳洲的 FIFO，fly-in fly-out）工人？三类人的行为模式天差地别；
- 数字化原住民旅客对个性化的期待一年比一年高，而留存压力也一年比一年大。

机场掌握的数据其实非常值钱：每一次停车预订都带着提前期、停留天数、停车区位偏好、和航班时刻的关联。但这些信号过去都"睡"在交易系统里，没有被翻译成营销可用的指令。

## 二、转折点：把停车数据当作客户画像的入口

布里斯班机场和 SAP Engagement Cloud 合作的起点没选 APP、没选会员体系，而是选了停车——这一点其实挺反直觉。

原因是停车这个行为虽然不性感，但每一次预订都暴露了大量结构化信息：什么时候预订、停多久、什么航班、停哪个停车场。把这些数据在 Engagement Cloud 里聚合起来跑模式，三类典型客群就自然浮现了——

- 商务旅客：停车时长短、偏好快速通道、临到出发前才预订、习惯一早的航班；
- 休闲旅客：提前很久预订、典型周末或假期出行、对家庭友好服务和促销敏感；
- FIFO 矿区工人：出行时间高度规律、跟着轮班节奏走，看重便利性和长期停车折扣。

这一步是整个项目最关键的判断：先从一个数据质量最稳定、信号最干净的业务（停车）切入，把客户分群跑通，再去往外延伸。很多客户上 Engagement Cloud 一上来就要"全渠道、全触点、所有客户"，结果数据质量不齐，画像跑出来稀稀拉拉，项目就胶着了。

## 三、After：三个动作，把画像变现

**动作一：差异化触达。** 商务旅客收到的是省时方案和快速通道，休闲旅客收到的是家庭套票和季节性促销，FIFO 工人收到的是轮班贴合的提醒和长停折扣。同一条停车业务，三种叙事，三种渠道节奏。

**动作二：交叉销售把停车跟免税店绑起来。** 这是机场场景里最值得拿出来讲的一招。一个旅客刚定完国际航班的停车，下一秒就被识别为"高概率免税购物者"，于是会在出发前几天收到一封带着免税店促销的邮件，到机场后再收一条 Web Channel 推送提醒去逛逛。停车预订客户还能拿到"停车 + 免税券"的打包折扣。

机场的非航空收入（停车、零售、餐饮）历来是利润大头，但跨业态的引流以前几乎只能靠物理的引导牌。现在用数据把"刚下飞机的我"和"应该去逛免税店的我"在系统里连成同一个人，引流就变成了营销自动化的一条规则。

**动作三：实时引擎接管现场。** Web Channel 和 SMS 被用来覆盖旅程中的关键时刻——延误通知、最后一刻的优惠、行程中临时插入的服务推荐。旅行场景的"时间敏感性"比一般电商高一个量级，这里如果还是靠批量邮件，黄花菜都凉了。

## 四、对中国出海企业怎么用

这个案例对应的几类做海外业务的中国企业其实蛮直接：

- 跨境电商和 DTC 出海品牌：你手里其实也有大量"用户高意图但被忽视的信号"——加购未付、下载未注册、复访未购、客服咨询未转化。布里斯班机场用停车做切入，电商完全可以从其中一类信号切入跑画像，比强求一开始就建一个 360° 视图更现实；
- 跨国机场、酒店、连锁餐饮、零售综合体：业态多、数据散，正好对得上布里斯班的处境。它示范的是怎么从一条业务线突破，再一条条接进来；
- 在华外企总部对接团队：这是一个能拿来跟全球营销老板对话的样本——欧澳市场用 Engagement Cloud 把营收做出来，亚太分支可以延着同一个产品栈接 Commerce Cloud / CDP，让本地的玩法落到全球的合规和数据架构里。

需要先泼一盆冷水的是——SAP Engagement Cloud 在国内还没有数据中心，纯内贸品牌目前买不了。这个案例对国内品牌唯一可参考的，是它的方法论，而不是采购清单。

## 五、最后说一句

布里斯班这两个数字漂亮，但漂亮的不是数字本身。漂亮的是它示范了营销云不是"群发更牛逼的工具"，而是"把数据翻译成营销动作的引擎"。停车数据本来谁都看不上眼，但只要肯把它当画像入口，就能撬出 28.5% 的归因营收同比。

这种从一条业务线切入、再横向接其它业态的打法，比一开始就推全栈、上 360°、动整个组织，落地概率高很多。看完案例总结一句话：先找一个数据干净的入口，把第一个画像跑通，再说全渠道。
