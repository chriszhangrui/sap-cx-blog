# SAP 只有 3% 客户用 Joule，77% 跑去哪了

今天看到一条消息值得聊聊。

DSAG（德语 SAP 用户协会）2026 年的投资调研刚出，里面有一个数据扎眼到不太想读第二遍：在已经把 AI 用例投产的 SAP 客户里，**只有 3% 跑在 SAP 自己的 AI 上，77% 都跑在别家**——Microsoft Copilot、自定义 LLM、第三方自动化各种混着用。

同一份调研后面还跟了一句 Gartner 的 2025 年 6 月预测：到 2027 年底，**40% 的 Agentic AI 项目会被砍掉**——成本失控、价值不清、风控做不上去，三件事任意一件都能让项目躺平。

这两个数字摆在 Sapphire 2026 那场"自治企业"的发布会旁边看，反差非常强烈。一边 SAP CEO Christian Klein 在台上喊出 50 多个 Joule 助手、200 多个 specialized agent、Autonomous Suite 把财务关账从几周压到几天；另一边客户基本没怎么用，Gartner 还预言一半要被砍。

说白了就是：愿景和现实之间，差着一道叫"AI 就绪度"的门槛。这道门槛不是 SAP 的市场材料里画的样子，而是 Philip Herzig（SAP CTO）在同一场 Sapphire 2026 上自己讲的那句——**"没有任何 AI agent 能弥补一个坏掉的数据模型。"**

## 三件事，单独都能让 Joule 卡住

IgniteSAP 这篇文章里讲了一件做客户对话很有用的事：把"AI 就绪度"拆成三个独立维度评估，不要混在一起谈。

**第一件，主数据治理。** Joule agent 跑在 SAP Knowledge Graph 上，Knowledge Graph 又依赖于客户现网的主数据。MDG 光有 license 不算数，要看有没有真的在跑：物料、供应商、客户主数据有没有 stewardship 流程、重复率有没有量化指标、数据血缘能不能追溯。ECC 时代留下的数据债务，不会因为迁到 S/4HANA 就消失。

**第二件，流程标准化。** Agent 跑端到端流程的前提是这条流程标准到"异常是少数"的程度——一个流程在某个职能里同时跑十几个变体，agent 不会变慢，会出错。SAP Signavio 在这件事上是诊断工具，能把客户某个职能下到底有多少个 active variant 直接量化出来。

**第三件，治理成熟度。** 客户有 AI 伦理政策不代表有 operational governance。真正要问的是：流程负责人有没有为 agent 输出明确背责？升级路径有没有跑通？哪些动作 agent 能自治、哪些必须人工守住。

## 诊断对话怎么开口

- **数据问题**：当主数据重复率上升时，谁来负责 remediation？让某个流程负责人当场走一遍——主数据质量问题怎么走到能修它的那个人？
- **流程问题**：某个职能下现在有多少个 active variant？最近一次"用 SAP 标准替换掉自定义流程"是什么时候？
- **治理问题**：今晚某个 Joule agent 做了一笔错误的应计入账——谁会先发现？通过什么机制？如何回滚？
- **高管理解**：董事会说"我们要做 AI-ready"的时候，他们具体想要的是哪些能力？

## 还有一条容易忽略的部署门槛

Joule agent 必须是 RISE with SAP 或 GROW with SAP 客户。本地 ECC 客户原本被排除，Sapphire 2026 上 SAP 做了部分让步：愿意承诺迁云的 ECC 客户可以拿到部分 AI 场景。RISE 客户第一年合同里会自动激活 3 个 Joule 助手；GROW 客户上线就给全套。

对中国出海企业、跨境电商和在华跨国公司来说，如果海外的 SAP 是 ECC 或本地 S/4，又想在海外业务上跑 Joule agent，先得规划迁云的时间表。

## 我的判断是

DSAG 那个 3% 对 77% 的数字，初看像在打 SAP 的脸，再看其实是在打整个 SAP 生态的脸——客户已经在 AI 上花钱了，只是钱没流到 SAP 自己的产品上。Joule、Knowledge Graph、Autonomous Suite 这套地基已经搭起来了，但客户的现网还在 ECC 或者半路 S/4 的状态，agent 跑不起来。

SAP 这次把 RISE/GROW 合约和 Joule 绑得更紧，本质是用合约杠杆撬迁云。但合约只能解决"能不能用"的问题，解决不了"用得动用不动"。能不能用得动，回到 Philip Herzig 那句话——数据模型、流程标准化、治理成熟度。

对中国出海企业、跨境电商和在华跨国公司来说，这一轮 AI 浪潮里真正决定竞争位次的，不是谁先买了多少 Joule license，而是谁的数据治理和流程标准化先做完了功课。SI 合作伙伴里能把"AI 就绪度评估"做成一项咨询能力的，未来两年溢价空间会被拉得很开。那 40% 被砍的 Agentic AI 项目，砍的不会是 AI，砍的是没做就绪度的客户。
