想象一个电商运营总监的周一早晨。她打开后台，面前摊着三份对账报告——一份来自东南亚的本地支付网关，一份来自欧洲的信用卡处理商，还有一份是北美市场的反欺诈服务商的异常告警。三个系统，三种数据格式，三个供应商的客服热线。上个月有一笔跨境退款在三个系统之间来回弹了两周才搞定，老板问她为什么退款率在报表里忽高忽低——她只能说"因为我们有三套不同的统计口径"。

这不是什么极端案例。做过全球化电商的人都知道，支付这一层是最让人头疼的基础设施之一。每进一个新市场就要接一个新的PSP，每个PSP有自己的API、自己的风控逻辑、自己的对账周期。到最后，支付团队的日常工作不是在优化转化率，是在对账和排查差异。

现在有人说，这个问题可以从根上解决了。

## SAP Unified Payment 来了

上周 SAP 和 Adyen 联合宣布了一个东西叫 SAP Unified Payment。名字很朴素，但做的事情挺狠的：把支付能力直接嵌进 SAP Commerce Cloud 里面，原生集成，一个平台搞定电商、POS和ERP的支付。

这意味着什么？以前你用 SAP Commerce Cloud 做电商，支付这块必须外挂一个第三方网关。Stripe也好、本地PSP也好，你需要做集成、做对接、维护中间层。现在SAP说，不用了。支付就长在 Commerce Cloud 里面，Adyen 的全球支付能力通过原生集成的方式提供。

![SAP Unified Payment](https://techafricanews.com/wp-content/uploads/2026/05/SAP-6.png)

SAP CX 的产品负责人 Balaji Balasubramanian 说了一句话，我觉得很关键：**"SAP Unified Payment 把支付原生地带进了客户体验的核心。"** 这不是在玩文字游戏。以前支付是电商的"最后一公里"，现在SAP想让它变成"第一公里"——从架构层面，支付数据和商业数据、用户行为数据在同一个平台里流动。

## 为什么找 Adyen

Adyen 不是随便选的。这家荷兰公司的核心卖点就是"一个平台覆盖全球"——单一合同、单一技术接口、数百种本地支付方式。它服务的客户名单里有 Uber、Spotify、Microsoft、LinkedIn。

Adyen CCO Roelant Prins 的原话是："Commerce 的演进速度已经远远超过了背后的金融系统。"他说得很直接——现在企业做全球电商，最大的痛苦不是前端体验，是后面那一堆七零八碎的银行对接、支付处理商、反欺诈工具。

SAP Unified Payment 想解决的就是这个：

- **全球可扩展性**：单一合同+单一接口，接入数百种本地支付方式
- **AI驱动的营收优化和风控**：基于Adyen处理过的超过万亿美元交易数据训练的AI，优化授权路由，识别忠实客户
- **深度集成**：横跨电商、POS和ERP，一套系统搞定全渠道

> "这不只是处理一笔交易的问题，是消除运营复杂性、降低欺诈、确保跨境对账像本地交易一样自动化的问题。"
> —— Roelant Prins, Adyen CCO

## 这步棋下给谁看

做售前的人可能会问：这跟我有什么关系？客户之前也能接支付啊。

关系大了。

第一，这改变了 Commerce Cloud 的竞争定位。以前客户选 SAP Commerce Cloud，支付集成是一个额外的项目——要评估网关、做POC、定制开发对接层。现在这个环节直接省掉了。对比 Salesforce Commerce Cloud（还在跟各种PSP做第三方集成）和 commercetools（还需要客户自己搭支付中间层），SAP这一步在TCO上直接拉开了差距。

第二，这个动作暗含了一个更大的趋势：SAP正在把 Commerce Cloud 从一个"电商引擎"升级为一个"商业运营平台"。支付原生化只是开始。当支付数据、订单数据、客户行为数据都在同一个平台里，下一步自然就是用AI去做智能路由、动态风控、实时对账。这跟 SAP 在 Sapphire 上喊的 Autonomous CX 是一条线。

第三，对中间件商和独立支付集成商来说，这是一个不太友好的信号。如果支付变成了平台的原生能力而不是需要集成的外部服务，那些靠做支付对接吃饭的SI项目会慢慢变少。

## 冷水时间

当然也有值得观察的地方。Adyen是唯一的支付伙伴吗？如果客户已经跟Stripe或者本地PSP有深度绑定怎么办？"开放支付框架"（open payment framework）的开放程度到底多大？这些问题在公告里没有完全讲清楚。

另外，SAP Commerce Cloud 在中国市场的支付生态（支付宝、微信支付、银联）能不能通过这个框架覆盖，也是一个悬念。Adyen 虽然支持支付宝和微信支付，但具体在 SAP Unified Payment 里怎么落地，还得看后续。

---

回到开头那个电商运营总监。如果 SAP Unified Payment 真落地了，她的周一早晨会变成什么样？

也许是这样的：打开 Commerce Cloud 后台，全球所有市场的支付数据在同一个dashboard里。退款状态实时可见，不用再去三个供应商后台里翻。AI已经自动把上周的异常交易标记出来了，她只需要确认处理方案。跨境对账？系统自动完成了。

她终于可以花时间想一想真正重要的问题了：怎么用支付数据去提升转化率，而不是怎么让三份报表的数字对得上。

这大概就是"支付原生化"真正的意义。不是少接一个API的事儿，是让支付从一个运维负担变成一个增长引擎。
