
# 改名之后，价目表才是真戏

今天看到一条消息值得聊聊。瑞士那家做 SAP CX 多年的实施商 Spadoom 在 4 月底放出了一份 2026 版的 SAP Engagement Cloud 定价指南，把这款营销自动化平台改名之后的两个版本、跟 Klaviyo / HubSpot / Salesforce / Braze / Adobe 这一圈竞品的实际月费区间、还有那些没人在销售 PPT 里讲的隐藏成本都拆开了。

说白了就是：SAP 从不公开价目表，Emarsys 改名之前也不公开，竞争对手也都把价格藏在"Contact Sales"按钮后面。结果客户在选型的时候，所有数字都是销售嘴里的故事，没法横向对照。Spadoom 这次干的事情，就是把这层窗户纸捅破了。

## 改名带出来的一个隐藏动作：从一款产品变成两款

2025 年底 SAP 把 Emarsys 改名为 Engagement Cloud 的时候，没几个人注意到背后还做了产品线重构——现在 SAP Engagement Cloud 这个名字下面卖的是两款定位完全不同的东西，价差能到三倍以上。

**Emarsys Edition 是原来的那个独立营销平台**——同样的引擎、同样的 60+ 预制营销战术、同样的全渠道能力，换了个名字。它跟 SAP 生态没强绑定，可以独立卖给任何企业。月费 $1,500 到 $5,000+，看联系人库规模和渠道用量。

**Enterprise Edition 是改名时新出的高端版本**，把 Emarsys 这个营销引擎跟 SAP CX 套件、S/4HANA 做了深度集成——Commerce Cloud 的弃单数据、S/4HANA 的订单状态变化、Service Cloud V2 的 case 触发，都能实时喂进营销自动化流。再加上 Joule AI 全栈接入营销工作流，再加上 SAP CDP 做画像融合不需要中间件。月费 $5,000 到 $15,000+，几乎都是绑在 CX 套件谈判里卖出去的。

**实施成本的差距更夸张**。Emarsys Edition 标准版 6 到 10 周、$30K 到 $80K；进阶版 10 到 16 周、$80K 到 $200K。Enterprise Edition 直接跳到 12 到 24 周、$100K 到 $300K+，因为集成范围完全不在一个量级——多了 S/4HANA 实时信号、Commerce Cloud 事件接入、CDP 画像统一、跨云旅程编排、Service Cloud V2 触发器、Joule 激活、外加多国部署本地化。

Spadoom 自己有一段挺扎心的话："见过有公司本该买 Emarsys Edition，结果买了 Enterprise Edition。他们多花了 2 到 3 倍的钱，集成能力却根本没用上，因为他们的 SAP CX 部署成熟度跟不上。"翻译过来就是——出海企业先别急着上 Enterprise Edition，除非 Commerce Cloud / Sales Cloud V2 / Service Cloud V2 已经在跑生产，否则那笔集成投资就是浪费。

## 那跟外面的对手比呢

**Klaviyo 是公开定价里最便宜的**。中小型出海电商、跑 Shopify 或 BigCommerce、没 SAP 底座的，Klaviyo 性价比无敌——价格透明、电商集成做得好、分析也够用。但它是为电商生的，复杂的 B2B 或者带门店的全渠道零售，就吃力。

**HubSpot Marketing Hub Enterprise 版 $3,600/月**，跟 Emarsys Edition 同档。HubSpot 强在广度——营销+销售+服务一站式；Emarsys 强在深度——多步骤旅程、实时个性化、60+ 预制战术。看你的痛点在哪。

**Salesforce Marketing Cloud 是房间里的大象**——装机量第一，价格也是同档约两倍。功能比拼上 Emarsys Edition 能用一半的钱做到差不多的事。它的优势是 Salesforce 生态原生集成。SAP 用 Enterprise Edition 讲的是同一个故事，只是换了个生态。

**Braze 是移动端首选**。如果主战场是 Push 通知、In-App 消息（典型场景：500 万月活以上的消费 App），Braze 做得比 SAP Engagement Cloud 更好。但邮件、短信、Web 个性化、预制战术这些，Emarsys 更强。

**Adobe Journey Optimizer 是 Adobe 生态绑定款**，必须有 Adobe Experience Platform 底座，价格起步就在 SAP Engagement Cloud 上面，且涨得很陡。只有重押 Adobe 的企业才会考虑。

最关键的判断题就一道：你是不是 SAP shop？如果是——Enterprise Edition 把跨系统集成的成本省下来了，因为别的营销平台想接 SAP 生态，自定义集成上来就是 $30K-$60K 的初始费、加 $15K-$25K/年的维护费。这一项就把 TCO 对比翻过来了。如果不是——Emarsys Edition 跟谁打都能打。

## 真正坑人的是那些没在合同里的隐藏账

- **数据清洗**：每个营销自动化项目第一步都是导联系人。导本身不难，难的是导进来的数据是脏的——重复记录、无效邮件、缺 consent 标志、三年没活跃的僵尸账户。预算上要给到实施费的 10%-20%。这一步不做，后面投递率崩盘、垃圾邮件投诉飙升、域名进黑名单。
- **邮件投递性**：有平台不等于邮件能进收件箱。SPF / DKIM / DMARC 配置、IP 预热（4-8 周渐进放量）、列表清洗、ISP 送达率监控——这些是 $5K-$15K 的活，外加上线后 90 天的监控。多数实施合作伙伴只做基础的域名配置，不做完整的投递性方案。
- **内容创作**：平台只负责自动化分发，谁来写邮件模板、主题行、产品推荐文案、动态内容、登陆页、SMS 文案、Push 文案？10 个 workflow 就要 30-50 个内容资产。$10K-$30K 给内容创作初期投入，除非内部团队能消化。
- **消息分发费**：SMS 单条欧洲 $0.04-$0.08、美国 $0.01-$0.03。10 万联系人每月发一次 SMS，年开销 $3K-$8K。Push 本身免费但前置接入 Firebase / APNS 要 $5K-$15K。
- **续约涨价**：根据 Licenseware 2025-2026 数据，SAP 云产品续约年涨幅在 10% 以上。$3,000/月的合同三年后能涨到 $3,630/月。签合同前必须谈续约价格上限（3-5%/年），同时锁定渠道附加费。
- **未充分使用的机会成本**：Engagement Cloud 自带 60+ 预制营销战术，多数企业上线了 5-10 个就再也不动了。licence 费用是固定的，每个没激活的战术都是收入留在桌上。

## 套件捆绑的逻辑

Spadoom 里有个数据值得记下来——根据他们的项目经验，三个以上 CX 产品打包能砍 20%-35% 的标价。每加一个 SAP CX 产品，对其他产品的集成成本反而会下降，因为数据模型和客户画像底座已经统一了。

这一点对中国出海品牌来说尤其重要：如果 Commerce Cloud 已经在 18 个月路线图上、CDP 是统一海外多市场画像的底座，那么 Engagement Cloud 的定价就该作为未来套件谈判的一部分提前锁——签了独立合同之后再谈套件折扣，能拿到的让步永远比一次性谈下来的少。

## 看完整篇报告，最值得记的就这么几条

- 先上 Emarsys Edition，等 SAP CX 底座成熟了再升 Enterprise Edition——别为还没用上的集成能力多花 2-3 倍的钱
- 60+ 预制战术先用起来再造轮子，能解决 90% 问题的预制方案不用，等于实施预算白扔
- 数据清洗、投递性、IP 预热三件事在上线前做完，上线后做就是九倍的代价
- 续约价格上限、联系人量级弹性、渠道附加费三项必须在签合同前谈进合同条款

我的判断是：Spadoom 这份指南最有价值的不是那些数字本身——具体合同里面价格波动太大，谁也不能照搬。真正值钱的是它把决策路径理清楚了——先回答自己是不是 SAP shop、CX 套件成熟到哪一步、营销团队能不能撑起多步骤旅程，再回到价格表上对位。

中国出海品牌做欧美、做拉美、做东南亚市场，营销自动化平台选型这件事每年都要做一次——选错了可能是双倍的钱、双倍的实施周期、然后还要回头补集成。这种时候手里能有一份独立第三方拆出来的账本，比销售 PPT 管用得多。

Engagement Cloud 改名这件事，到现在为止大家讲得最多的是改名背后的事件总线开放、是 Joule 接进营销工作流。但这次 Spadoom 拿出来的角度——账本本身——可能才是更多决策者真正需要的那块拼图。
