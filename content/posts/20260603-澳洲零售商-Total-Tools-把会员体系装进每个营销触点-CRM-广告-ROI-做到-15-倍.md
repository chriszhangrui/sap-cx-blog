零售这两年有个挺明显的趋势——会员体系从一个"独立板块"变成了所有营销动作的底层。以前会员是 CRM 团队管的事，邮件团队管邮件、广告团队投广告、门店团队做活动，各干各的；现在但凡跑得起来的零售品牌，都在试图把会员数据穿到每一个触点里去，让每一次互动都"知道这个人是谁"。

这条路说起来简单，做起来难——难就难在数据散在十几个系统里，营销团队没法实时拿来用。澳洲最大的专业工具零售商 Total Tools 在这条路上跑了一段，数字相当能说明问题：CRM 广告 ROI 做到 15 倍，会员体系线上注册涨了 200%，活跃客户涨了 30%，自动化邮件的打开率比常规营销邮件高 16 倍。这不是渐进式改进，是质变。

把它的做法拆开来看了一遍，里面有几个判断挺值得做出海零售和跨境 B2B 工具的同行参考。

## 先说说 Total Tools 是谁，痛点在哪

Total Tools 是澳洲最大的专业工具连锁，做的是 B2B 偏多一点的生意——客户基本是各种工种的师傅：木工、电工、水管工、汽修、装修队。100 多家加盟门店，线上 SKU 两万多。这种业态有两个特点：一是客户黏性极强（师傅干一行用一套工具，不会随便换品牌），二是客户行为差异极大（电工和木工要的东西完全不一样，但你不能让木工收到电工的促销）。

他们之前的痛是非常典型的"大数据小应用"——数据有，但散在邮件平台、电商后台、广告系统、门店 POS、忠诚度系统里，互相不通气。客户在网站搜了一把电锯，邮件里推的还是上周浏览过的螺丝刀；忠诚度积分攒了一堆，结果在哪里也用不爽。

Total Tools 的 Group Head of Loyalty 在原文里说得很直接："我们想在客户感兴趣的那一刻、用对的渠道、说对的话。"听起来像市场部老生常谈，但要把这句话落地到系统层面，是个硬仗。

## 他们做对的第一件事：数据先合，工具后用

Total Tools 选的是 SAP Engagement Cloud（也就是 SAP CX 这条线里专门做 B2C 营销自动化的产品，老用户可能更熟它的旧名 Emarsys）。这个产品的特点是自带一个统一客户视图层——把网站行为、销售数据、商品数据、业务数据、门店交互这五类数据全部 stitch 到一起。

这一步是地基。地基没做好的品牌，后面再多花哨的 AI 玩法都是空中楼阁。做项目这些年见过太多客户上来就问"你们的 AI 推荐准不准"，但他们连基础的统一 ID 都没拉通——同一个人在 App 和网站上是两条记录，那 AI 推什么都白推。

![Total Tools 数据架构图](https://emarsys.com/app/uploads/2023/04/01-Success-Story-Total-Tools-EN.png)

Total Tools 的做法是把"数据层—个性化引擎—自动化—跨渠道执行"这条主链路一次性搭起来。比较欣赏的一个细节是：他们没有先做一个大而全的 CDP 项目（那种项目动辄一年半起步），而是把数据接入和首批自动化场景并行推。这是务实做法——业务部门看不到效果，数据治理就走不下去；先用先见效，反过来推动更深的数据接入。

## 第二件事：用预制 tactic 把上线节奏压到极短

原文里有一句话印象很深——"Total Tools 几乎是立刻就上线了 20 个关键自动化"。"立刻"这个词在企业 CRM 项目里基本是奢望。

秘诀在于 SAP Engagement Cloud 里有个东西叫 automation center + pre-built tactics——简单说就是把零售行业最高频的几十个营销场景（弃单挽回、欢迎旅程、加入会员、浏览未购、补货提醒……）做成了开箱即用的模板。营销团队不用自己从零搭流程图，选模板填参数就能上。

这个产品逻辑非常符合零售业的现实——零售品牌的营销团队人不多，IT 资源更紧，没法每搭一个旅程都开一次需求会。预制 tactic 的本质是把"最佳实践"产品化，让业务部门自己能跑。

出海做品牌的中国企业最该看明白这点：你在国内可能习惯了一切找代运营做、一切找乙方搭，但海外市场（尤其是欧美澳）的运营节奏要求营销同事自己能动手。选工具的时候要把"营销团队自己能不能用起来"作为一条硬指标，而不是只看技术参数。

## 第三件事：把忠诚度从"独立模块"改成"贯穿所有渠道的属性"

Total Tools 重启了它的会员体系（叫 Insider Rewards），关键改动不是积分规则有多复杂，而是把会员属性嵌进了每个渠道、每次互动里。这听上去是套话，落到产品层面其实是几件具体的事：

- 邮件不再有"会员通讯"和"普通通讯"之分，所有内容都根据会员等级动态调整
- 网站推荐位会根据会员的历史购买行业（电工/木工/油漆工）变换商品
- 门店 POS 也接入了同一套客户画像，店员能看到这个客户线上的浏览记录
- 个性化优惠券是动态生成的，不是预先批量发放

效果是数据自己说的——会员体系上线后线上注册涨 200%，活跃客户涨 30%。这个 30% 不是用普通指标算的，是 Total Tools 用 SAP Engagement Cloud 里的 Smart Insight 定义的"实质活跃"——也就是除了打开邮件，还有真实购买行为或互动深度的客户。

![Total Tools 渠道与忠诚度整合](https://emarsys.com/app/uploads/2023/04/02-Success-Story-Total-Tools-EN-2.png)

## 最值得抄的一招：把 CRM 数据反哺投放

Total Tools 那个 15 倍的 CRM 广告 ROI 怎么来的？是把 SAP Engagement Cloud 里的客户画像和分群直接同步给了 Google Ads 和 Facebook 广告平台，做的是 1st-party data activation。

这不算新概念但极少品牌做透。多数品牌的做法是：把全量客户名单丢给 Meta 做 Lookalike，希望平台帮自己找像样的人。但这种粗放方式 ROI 越来越低，因为名单里有大量已流失客户、低价值客户。

Total Tools 的精细之处是分群打——比如"过去 90 天浏览过电锯但没下单"的电工人群单独打一组广告，用对应的素材；"会员体系金卡客户的休眠人群"打挽回广告；"刚买过新工具箱的客户"打配件交叉推荐。每一组人群都有清晰画像和对应素材，转化效率自然就上来了。

出海做 DTC 的中国品牌可以重点参考这一招——海外的广告流量越来越贵，把 CRM 沉淀的高质量分群反哺到投放，比单纯堆预算扩量有效得多。这也解释了为什么 SAP Engagement Cloud 在欧美零售圈的渗透率比一些纯营销工具高——它对零售业的数据流转和投放联动这条链路理解得更深。

## 这个案例对中国出海品牌的启发

Total Tools 是澳洲本地连锁，业态和中国出海品牌不完全一致，但有几条经验是共通的，做跨境零售或跨境 B2B 工具的同行可以对照看看：

- 不要先建大数据中台再谈营销——先把高频几个场景的数据流跑通，让业务部门见到效果，再扩展数据范围
- 选营销工具时把"营销团队是否自己能用"作为硬指标，海外市场没法事事依赖代运营
- 会员体系不要做成独立产品线，要做成穿在所有渠道里的属性
- 1st-party data activation 是当下广告 ROI 的关键解法，CRM 必须能和投放系统直接握手

最后说一点产品层的判断。SAP Engagement Cloud 在 2024 年从原来的 Emarsys 品牌升级合并进 SAP CX 主线，现在 SAP 内部把它定位成"Intelligent CX 里的 customer engagement 解决方案"。和 SAP S/4HANA、Commerce Cloud、CDP 之间的数据互通会是它接下来一年很重要的演进方向。对那些已经用了 SAP ERP 或 Commerce 的中国出海品牌来说，把 Engagement Cloud 接进来，能拿到的数据通畅度比纯第三方营销云会高一档。
