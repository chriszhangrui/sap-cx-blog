今天看到一条消息值得聊聊。CRN（这家是美国渠道圈的老牌媒体，专门服务SI、经销商、ISV）这周专门写了一篇 SAP Sapphire 2026 的复盘，但视角跟之前几乎所有报道都不一样。

大部分文章都在讲 SAP 发了什么、Joule Work 长什么样、Christian Klein 又喊了什么愿景。CRN 不一样，它把镜头对准了一个被多数人忽略的数字——**1亿欧元**。这是 SAP 拿出来砸给合作伙伴生态的钱。

说白了就是：这场 Agent 牌局，SAP 自己一个人玩不转。它需要 Lemongrass、cbs、EY、PwC、Accenture 这些 SI 入场陪跑。CRN 正好捕捉到了这层生态算计。

## JPMorgan 的 CFO 在台上说了一句很扎心的话

Sapphire 开幕主题演讲，SAP 请了一位重量级嘉宾——摩根大通 CFO Jeremy Barnum。他作为甲方代表，开口的话不是夸 SAP，而是给所有 CIO 提了个醒：

> "在财务部门，把 AI 撒在已经坏掉的业务流程上，最大的风险是你错过了清理技术债务、彻底现代化整个生态的机会。从我们的角度看，AI 的水平上限就是它下面那层数据和流程的水平。"

这句话翻译成大白话——**烂流程加 AI 等于自动化的烂流程**。这位 CFO 把球踢给了 SAP 和所有 SI：你们想卖 Agent，先帮我把底下的脏活干干净。

## 这1亿欧元，到底投给谁

这笔钱不是直接给客户的补贴，而是给生态伙伴的弹药包。CRN 透露的信息是这笔钱有两个用途：

- 帮合作伙伴把 SAP 自研的 Joule Assistants 部署到客户那边
- 让合作伙伴在 Joule Studio 上自建专属的行业 Agent 卖给客户

第二个用途更值得琢磨。SAP 的潜台词是：建 Agent 的工具我开放给你了，你去赚客户的项目费。这不是 SaaS 时代的渠道返点逻辑，是 PaaS 加生态联营的玩法。

## Lemongrass 的 CTO 说了大实话

Lemongrass 是 SAP 圈里专门做迁移的咨询公司。它的 CTO Eamonn O'Neill 在 Sapphire 之前接受了 CRN 采访，他给客户的建议很直白：

> "今天就用 AI，但不要停下现代化的脚步。继续走 SAP 路线图，上 S/4HANA、上 RISE，你做得越多，能拿到的创新就越多。那些不在 SAP 升级和 AI 部署上并行推进的客户，正在错失大幅降本的机会。"

这段话信息量挺大。它揭示了 SAP 这次 Sapphire 的真实意图——**把 AI 当成 ECC 迁 S/4HANA 的胡萝卜**。

CRN 给了一个数字：超过一半的 SAP 核心 ERP 客户还在跑本地部署，而 SAP 已经明确——大部分新的 AI 能力只给云客户。再加上 ECC 主流支持 2027 年底到期，这就是一根明晃晃的大棒。

## EY 那段话其实是给所有 SI 的提醒

EY 全球副主席 Julie Teigland 接受 CRN 采访时说，过去一年 EY 和 SAP 的关系"深化得令人难以置信"。她的客户在做 SAP 迁移时，会让 EY 评估技术债、梳理工作流、看数据结构、查网络安全。

然后她说了一句关键话："SAP 在 Sapphire 上传递出一个非常强烈的信号——他们需要技术伙伴、云平台、解决方案商、战略服务商一起把这件事做成。"

翻译过来：SAP 在 Sapphire 上的潜规则是，**生态分工已经重新洗牌**。SAP 自己做平台和核心 Assistant，行业 know-how 和迁移脏活交给生态。

## CX 视角下，这个生态变化意味着什么

CRN 这篇文章主要在讲 ERP 圈，但同样的逻辑套到 CX 上其实更明显。

SAP 这次 Autonomous Suite 的五个域里，CX 是其中一个——marketing、commerce、sales、service 都有 Joule Assistant 排着队上线。但 CX 项目和 ERP 项目的差异在于：CX 高度依赖**行业流程**和**本地化运营**。零售的会员体系、制造的经销商网络、to B 的复杂询价、售后的现场服务——每一个都是 know-how 密集型的。

SAP 自己出 50 个 Assistant 编排 200 多个 Agent，覆盖的是横向通用场景。真正能跑起来的项目级 Agent，几乎一定要 SI 在 Joule Studio 上重新打磨。这就是 1亿欧元基金真正的价值。

## 几个值得留意的细节

- Sid Misra（SAP BTP 的 CMO）专门跟 CRN 说，统一平台让伙伴可以"为客户开发 AI 扩展和定制 Agent"——这话只对生态讲
- RISE/GROW 改版后，第一年合同里就锁定 3 个 Joule Assistant 的激活承诺，Max Success Plan 还会扩展到全企业
- Lemongrass 和 cbs 联合操盘的 Propelis（一家全球营销服务公司）共享 ECC 拆分迁 S/4HANA 项目，8 个月就完成——这是 SAP 想推的样板

## 我的判断

SAP 这场 Agent 牌局，本质是把过去十年偏向自营的 intelligent enterprise 叙事，重新切回到生态联营。原因很现实——光靠自己卖 Joule，撬不动那一半还在 ECC 上的客户基本盘。

1亿欧元这个数字其实不算大（对比 Microsoft 给 Copilot 的投入是另一个数量级），但信号意义大于金额——它告诉所有 SI：这一轮 Agent 浪潮里，SAP 给你留了座位，但桌上的菜要你自己加工。

对国内做 SAP CX 的同行来说，最值得关注的不是 Joule Work 那个炫酷的 UI，而是 Joule Studio 上的行业 Agent 怎么打磨成可复用资产。这才是未来三年的真正机会窗口。

至于跟客户怎么讲——参考摩根大通 CFO 那句话最稳：先把流程和数据底子修好，再谈 Agent 才有意义。撒胡椒面式上 AI，最后大概率变成"自动化的烂流程"。
